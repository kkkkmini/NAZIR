## 4. 디자인에 영향을 주는 구조적 제약

- **비회원 서비스.** 회원가입·로그인·마이페이지가 없다. 관객의 "로그인"은 본인인증 세션(30분/조회용 10분 권장)이다.
- **브라우저 바인딩.** 인증 세션과 주문 접근은 같은 브라우저에서만 유효하다. 다른 기기에서 예매를 보려면 조회용 본인인증을 다시 한다.
- **외부 화면 2개.** 본인인증(NICE)과 결제(토스 결제창)는 외부 화면이다. 복귀 결과 페이지는 문서에 경로가 있다: `/identity/complete`, `/booking/orders/{orderId}/result`.
- **서버 상태 우선.** 좌석·주문·결제 상태는 서버 응답만 표시한다. 브라우저 타이머는 표시용이다.
- **주문 상태 9개**(PENDING, PAYMENT_CONFIRMING, PAYMENT_UNKNOWN, REVIEW_REQUIRED, UNFULFILLED, PAID, CANCELED, EXPIRED, REFUNDED)가 관객·관리자 화면 양쪽에 나타난다.
- **관리자 역할은 2개**(SUPER_ADMIN, STAFF). 현장 스태프 전용 역할은 없다.
- **관리자 변경은 열거된 action만** 가능하다. 임의 수정 화면을 만들지 않는다.
