# 루미나아트홀 좌석 안내도 — 참고 자료

- 원본: `lumina-art-hall-seat-guide.jpg` (2026-11-24 사용자 제공, 현장 게시물 사진)
- 용도: A3-3 좌석 배치도(SVG) 제작의 **디자인 기준 참고 자료**. 판매 좌석·구역·가격·좌석 ID의 근거가 아니다.
- 현재 A3-3은 기존 [DEV] 78석 fixture를 유지한다.

## 이미지에서 읽은 내용 (판독, 확정 아님)

무대 상단. 각 열은 통로를 사이에 두고 좌·우 블록으로 나뉜다(J열은 좌측 블록만).

| 열 | 좌 블록 | 우 블록 | 합계 |
|---|---|---|---|
| A | 1–8 | 9–16 | 16 |
| B | 1–9 | 10–17 | 17 |
| C | 1–12 | 13–21 | 21 |
| D | 1–12 | 13–20 | 20 |
| E | 1–13 | 14–22 | 22 |
| F | 1–13 | 14–21 | 21 |
| G | 1–15 | 16–24 | 24 |
| H | 1–16 | 17–24 | 24 |
| I | 1–11 | 12–20 | 20 |
| J | 1–15 | — | 15 |
| **계** | | | **200** |

- 좌 블록은 열마다 왼쪽 끝 위치가 다르다(뒤로 갈수록 넓어짐, H열이 가장 넓음). I·J열 좌측은 콘솔 때문에 들여 있다.
- 출입문: 좌측 B열 옆(→), 우측 J열 아래(↑). 콘솔: 좌측 하단(I·J열 왼쪽).
- 사진 촬영 각도·반사로 칸 위치는 근사치다. A열 13번 등 일부 숫자는 반사로 흐리다.

## 실제 배치 적용 전 확인 필요

1. 실제 판매 대상 좌석 수(200석 전부인지)
2. 판매 제외 좌석(콘솔·출입문 주변, 운영석 등)
3. 좌석별 구역 구분
4. 구역별 가격(E-004)
5. 좌석별 가격 override
6. 안내도 번호와 백엔드 좌석 ID 매핑 — 안내도 번호를 그대로 ID로 쓰지 않는다
7. SVG seat ID와 DB `seats.svg_seat_id` 매핑 규칙(E-003)
8. 출입문·콘솔의 실제 위치와 배치도 표시 여부
9. 휠체어석 등 특수 좌석 유무

백엔드 좌석 데이터와 SVG 식별자가 일치하는 시점에 SVG 배치도를 제작해 적용한다.
